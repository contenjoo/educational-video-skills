# 첫 실행과 오류 복구

[English](first-run.en.md) · 한국어 · [日本語](first-run.ja.md)

1. 스킬이 실제로 검색되고 본문을 읽었는지 확인한다. 새 작업 폴더에 최소 1편을 만들고 기존 강의는 보존한다.
2. 원본 녹화를 받아 길이·영상 스트림·실제 조작을 확인한다. 원본이 없으면 필요한 촬영 목록을 안내하고 녹화된 것처럼 꾸미지 않는다.
3. 필수 도구와 네트워크를 먼저 확인한다. 패키지를 설치할 수 없으면 렌더 단계로 넘어가 같은 실패를 반복하지 않는다.
4. 내레이션이 필요한 영상은 음성을 먼저 한 문장 시험한다. 실제 오디오 스트림·길이·음량을 확인하고 비어 있는 파일을 성공으로 처리하지 않는다.
5. 실제 녹화와 요청한 자막·음성이 들어간 짧은 구간을 렌더하고, 성공하면 전체 제작으로 이어간다.

## 실제 검증에서 관찰한 경계

| 관찰 | 확인·대응 |
| --- | --- |
| CLI 로그인 상태는 정상인데 실제 호출은 OAuth 만료 오류 | 해당 제품의 정상 로그인/갱신 경로로 복구한다. 토큰을 추출·복사하거나 인증 설정을 공개하지 않는다. 갱신 뒤 실제 모델 호출을 한 번 확인한다. |
| 설정된 모델명이 계정에서 지원되지 않음 | 해당 호스트의 지원 모델을 확인하고 현재 실행에 사용할 모델을 선택한다. 기존 사용자 설정을 임의로 덮어쓰지 않는다. 기본 설정 실행도 진단 선택지이며 변경 내용을 알린다. |
| `Could not resolve host` / 레지스트리 연결 실패 | DNS·프록시·실행 환경의 네트워크 허용 여부를 구분한다. 호스트의 정식 승인 경로를 사용하고 보안 기능을 끄지 않는다. |
| macOS `say`가 `Operation not permitted` 또는 4KB 정도의 빈 파일 생성 | 파일 존재와 음성 생성은 다르다. FFprobe로 실제 길이·스트림을 확인한다. 호스트 승인 실행, 사용자 녹음, 다른 이용 가능한 TTS 중 선택한다. |
| 상태 저장소가 읽기 전용 / 앱 서버 시작 권한 오류 | 선택한 CLI가 정상 실행에 필요한 자신의 상태 폴더를 사용할 수 있는지 확인한다. 사용자 설정·인증 파일을 다른 경로로 복사해 우회하지 않는다. |
| 한국어 키 입력 뒤 공백만 남음 | 실제 편집기의 지원 입력 요소에 UTF-8 텍스트를 넣고 화면과 저장 내용을 다시 읽는다. 같은 키 입력을 반복하지 않는다. |

일부 도구만 가능한 경우 대본·소스·무음 미리보기를 보존할 수 있지만, 필수 음성 또는 Remotion 렌더가 빠졌다면 결과에 명시한다. 다른 방식으로 만든 MP4를 Remotion 렌더 성공으로 세지 않는다.

## 브라우저 URL 확인 단계에서 녹화가 시작되지 않을 때

- 창 제목을 읽었어도 현재 URL을 검증하지 못했다면 `녹화 시작 전 차단 / Remotion 렌더 미시도`로 보고한다. 브라우저 도구의 실패만으로 Remotion이 지원되지 않는다고 결론 내리지 않는다. 정확한 내부 원인은 진단 로그 없이는 확정하지 않는다.
- URL 신뢰 확인을 우회하거나 보안 설정을 끄지 않는다. 같은 오류가 반복되면 자동 녹화를 중단한다. 창 재열기·탭 하나만 남기기·앱 업데이트를 근거 없이 반복 요청하지 않는다. 원인이 달라졌다는 진단 근거가 있을 때만 재시도한다.
- 기존 녹화 파일이 제공되면 브라우저 제어 없이 길이·영상 스트림·필요한 실제 조작·개인정보를 확인하고 편집을 이어간다. Chrome이나 특정 사이트가 열려 있어야 파일을 편집할 수 있는 것은 아니다. 파일이 없다면 필요한 동작을 짧게 직접 녹화해 달라고 안내하고, 확보 전에는 녹화 완료로 보고하지 않는다.
- 사용자가 무음·자막 영상을 요청했다면 TTS 생성이나 음성 제공을 필수로 요구하지 않는다. Remotion 결과물은 `python scripts/check_media.py lesson.mp4 --silent --srt lesson.srt --expected-text captions.txt`로 검사한다. `captions.txt`는 승인된 전체 표시 문구다. 이 옵션은 음성이 있는 영상의 음성 검사를 생략하는 용도가 아니다. 캡처 전용 `render_lesson.py`는 여전히 내레이션 입력을 요구하므로 무음 제작 지원으로 오인하지 않는다.
- 도구 복구를 요청받으면 제품·도구 버전, 오류 원문, 녹화 시작 여부를 확인한다. 다른 컴퓨터에서 성공한 테스트를 해당 Windows 환경 복구의 증거로 쓰지 않는다.

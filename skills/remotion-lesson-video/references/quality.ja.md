# 最終動画の確認

[한국어](quality.md) · [English](quality.en.md) · 日本語

ファイルの正常性と、学習者が課題を実行できるかを別々に評価する。

| 項目 | 確認内容 | 限界 |
| --- | --- | --- |
| 課題 | 実操作と保存結果 | メニューの存在だけでは完了ではない |
| ファイル | SHA、長さ、解像度、fps、映像・音声ストリーム | 正常なコンテナーでも授業内容は間違い得る |
| 全編デコード | 映像・音声を最後までデコード | 人による全編視聴ではない |
| 画面 | クリック対象、拡大、カーソル、文字、重なり、結果 | 抽出フレームの確認と全編視聴を区別する |
| 音声 | 抜け、繰り返し、途切れ、無音、音量、ピーク | 音声認識は自然な発音を保証しない |
| 字幕 | 音声との一致、メニュー名、欠落、改行、場面範囲 | 要約カードは全文字幕ではない |
| 人の再生確認 | 実際に見た範囲・聴いた範囲 | 未実施の全編聴取・実機確認は未実施と記録する |

```bash
ffprobe -v error -show_format -show_streams -of json output/lesson.mp4
ffmpeg -v error -i output/lesson.mp4 -f null -
```

実際のファイルパスを使う。ツールがなければ利用可能なプレーヤーやメタデータの検査だけを報告し、結果を推測しない。音量にはEBU R128など適切な尺度を使い、平均dBをLUFSと同一視しない。配信先と声に合う目標を設定する。黒画面や無音が意図的な場合もあるため文脈を確認する。

最終SHA-256、検査時刻、コマンド・ツール、対象範囲、問題、未実施項目を記録する。Python hashlibなどでハッシュを計算する。変更後の動画は新しいハッシュに基づいて確認する。

共通のファイル・SRT・台本チェッカー、警告の扱い、公開先確認は[制作時の確認事項](production-checks.ja.md)に従う。技術検査だけで発音や公開版の差し替えを保証しない。

# 최종 영상 검수

사용자가 바로 따라 할 수 있는지와 파일이 정상인지 분리해서 확인한다.

| 항목 | 확인할 내용 | 한계 |
| --- | --- | --- |
| 실제 과업 | 원본 서비스에서 조작하고 결과 저장 확인 | 메뉴 존재 확인만으로 과업 성공을 대신하지 않음 |
| 파일 | 해시, 길이, 해상도, fps, 영상·오디오 스트림 | 컨테이너가 정상이어도 교육 내용은 틀릴 수 있음 |
| 전체 디코드 | 영상·오디오 끝까지 오류 없이 디코드 | 사람이 전편을 본 것과 다름 |
| 화면 | 클릭 위치, 확대, 커서, 글자 크기, 자막 겹침, 결과물 | 표본 프레임 검사와 전편 관찰을 구분 |
| 음성 | 누락·중복·잘림·긴 무음·음량과 피크 | ASR 전사는 발음 자연스러움 전체 검수를 대신하지 않음 |
| 자막 | 음성과 정렬, 메뉴명, 누락, 줄바꿈, 장면 경계 | 요약 문구를 전체 발화 자막으로 소개하지 않음 |
| 사람 재생 | 실제 수행한 구간과 청취 여부 기록 | 수행하지 않은 전편 청취·실기기 검수는 미실시로 표시 |

FFmpeg/FFprobe가 있으면 다음 명령을 실제 파일에 맞춰 쓴다. 도구가 없으면 결과를 추정하지 말고 사용 가능한 플레이어/메타데이터 검사 범위를 기록한다.

```bash
ffprobe -v error -show_format -show_streams -of json output/lesson.mp4
ffmpeg -v error -i output/lesson.mp4 -f null -
```

음량은 필요 시 EBU R128 등 적절한 측정으로 확인하고, 단순 평균 dB를 LUFS로 표기하지 않는다. 목표 음량은 배포처와 음성 특성에 맞춘다. 검은 화면·무음 검출은 의도한 장면일 수 있으므로 자동 실패로 단정하지 않는다.

검수 기록에는 최종 파일 SHA-256, 검사 시각, 수행 명령/도구, 검사 범위, 발견한 문제, 미실시 항목을 포함한다. 파일 해시는 Python 표준 라이브러리 `hashlib` 등 환경에 맞는 도구로 계산한다. 영상 수정 후 이전 파일의 검수 기록을 그대로 재사용하지 않는다.

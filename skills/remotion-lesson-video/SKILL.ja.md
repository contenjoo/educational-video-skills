# Remotionで教育動画を作る

[한국어](SKILL.md) · [English](SKILL.en.md) · 日本語

実際の画面録画を使い、学習者が操作を完了できる教育動画を作る。ClaudeとCodexで同じ手順を使い、特定のOS・アカウント・声・録画アプリ・個人用パスを前提にしない。

## 使用言語

利用者が明示した言語を優先する。指定がなければ依頼文の言語で説明する。韓国語・英語・日本語に対応し、案内文の言語と動画・音声・字幕の言語は別々に扱う。別の動画言語が指定されていれば、その指定を維持する。日本語の固有名詞・読み方・実際のメニュー名を確認し、日本語対応フォントと音声を選ぶ。コマンド・API名・JSONキー・検査用ステータスは翻訳しない。

## 過去の失敗を繰り返さない

既存プロジェクトの実際の入力とレンダラーを先に確認する。計画・台本 → 実画面と台本の修正 → 音声 → 短い完成見本と複雑な代表場面 → 一括制作 → 最終確認 → 依頼された公開先の確認、の順で進める。画面・強調位置・不自然な音声を大量制作の前に直す。各段階で承認を取り直すという意味ではない。

実行前に[制作時の確認事項](references/production-checks.ja.md)を読み、関連項目を適用する。クリック前後の状態、強調表示のタイミング、台本・音声・カリキュラムの一致、言語別の納品物、学習者に見える版を確認する。既存の有効な検査結果を再利用し、書類を増やさない。同梱の `scripts/check_media.py` を使い、自動検査で判断できない項目は未確認とする。

## 開始と再開

- スキルのフォルダーで `python3 scripts/preflight.py --mode remotion --network` を実行する。`--tts` はmacOSの韓国語システム音声を使うときだけ追加し、ほかの環境で `say` を必須にしない。準備検査の成功は制作成功ではない。
- 対象者、課題、学習成果、制作言語、長さ、素材、納品物を確認する。固定の尺より操作の完了を優先する。重要な不足事項だけを質問し、合理的な仮定は明示する。
- 既存ファイルと進捗を読み、変更不要な録画・音声・字幕を再利用する。
- ターミナル、ファイル、録画ツール、音源、動作するRemotion環境を確認する。実行ツールがなければ台本と場面表を準備し、不足する入力を示す。スキルのインストールでツールやアカウント権限は増えない。
- セットアップとレンダリングは[制作手順](references/production.ja.md)を参照し、既存のパッケージ版とコマンドを維持する。
- 失敗時は[初回実行と復旧](references/first-run.ja.md)で認証・ネットワーク・音声・レンダリングのどこが止まったか切り分ける。同じ失敗を繰り返さず、音声付きの依頼に無音の代替物を完成品として渡さない。

## 実画面素材と授業設計

1. 実際に課題を操作し、保存された結果を確認する。メニュー名、権限、プランによる違いを記録し、アカウント固有の機能を想像で補わない。
2. 入力、クリック、メニュー、ドラッグ、カーソルの実録画を使う。静止画に模擬カーソルを載せたものは録画ではない。明示されたスライド形式は尊重し、正確に表示する。
3. 必要なウィンドウ・タブだけを架空の練習データで撮り、個人情報を除く。録画手段や権限がなければ提供素材を使うか必要なクリップを列挙する。
4. 課題 → 実操作 → 結果確認 → 練習時間で場面を構成する。因果関係を残しながら待ち時間と失敗を省く。
5. 読みやすさに必要な分だけ拡大し、録画のカーソルを優先する。強調の四角は同一フレーム・解像度・拡大率で実対象と照合し、画面遷移で消す。

## 音声・字幕・編集

- 本人の録音または利用可能なTTSを使う。特定の有料サービスや個人用音声を必須にしない。声の複製にはその声の利用許可が必要である。
- 必要なら読み上げ用と表示用の台本を分ける。制作メモを学習者向け画面に残さない。
- 場面と意味のまとまった短い字幕を実音声に合わせる。文字数による推定を正確な整列と扱わず、メニュー名・固有名詞・改行を直す。
- 録画、音声、字幕、拡大はRemotionのフレーム時刻で制御する。導入版の公式仕様と照合する。CSS時刻や制御されていない乱数で動きを決めない。
- 翻訳版も学習目標と操作順を保ち、メニュー・音声・字幕を対応させる。字幕の翻訳だけでは完全なローカライズにならない。

## 確認と納品

長時間レンダリングの前に代表場面を確認する。通常の作業で再承認を要求せず、依頼の範囲で進める。[品質確認](references/quality.ja.md)に従い、技術検査、自動音声照合、人の再生・聴取を分けて記録する。未実施の検査を合格にせず、編集後は新しいハッシュで特定した最終ファイルを確認する。

依頼されたMP4、字幕、台本、プロジェクトソース、再現コマンドを渡し、必要ならサムネイルやチャプターを付ける。ファイル生成、アップロード、公開、講座差し替えを別々の行為として扱い、それぞれ実際の結果を確認する。

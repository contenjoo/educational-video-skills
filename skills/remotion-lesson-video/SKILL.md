# 리모션 교육영상 만들기

학습자가 실제 화면을 보고 과업을 끝낼 수 있는 교육영상을 만든다. Claude와 Codex에서 같은 절차를 사용한다. 특정 운영체제·계정·목소리·녹화 앱·개인 경로를 전제하지 않는다.

[English instructions](SKILL.en.md) · 한국어

## 시작과 재개

- 첫 실행에는 이 스킬 폴더 기준 `python3 scripts/preflight.py --mode remotion --network`로 도구와 npm 연결을 확인한다. macOS 시스템 음성을 선택할 때만 `--tts`를 추가한다. 다른 운영체제나 음성 소스에서는 `say`를 요구하지 않는다. 출력 상태는 준비 조건 확인이며 영상 제작 성공이 아니다.
- 대상, 학습 목표, 실제로 만들 결과물, 언어, 예상 분량, 원본 자료, 원하는 산출물을 요청에서 파악한다. 분량보다 수행할 과업을 먼저 정한다. 중요한 정보만 질문하고 사소한 조건은 합리적으로 정해 알린다.
- 기존 파일과 상태 기록을 확인해 이어서 작업한다. 이미 만든 녹화·음성·자막은 변경이 필요한 부분만 다시 만든다.
- 터미널과 파일 작업, 지원되는 녹화 도구, 음성 소스, Remotion 실행 환경을 확인한다. 도구가 없는 Claude 웹 환경 등에서는 제작 가능한 대본·장면표까지 진행하고 필요한 원본/실행 환경을 구체적으로 안내한다. 스킬 설치가 도구나 계정 권한을 제공하지는 않는다.
- 새 프로젝트 구성과 렌더가 필요하면 [references/production.md](references/production.md)를 읽는다. 기존 프로젝트의 패키지 버전과 실행 명령은 먼저 확인하고 보존한다.
- 실패가 나면 [references/first-run.md](references/first-run.md)의 실제 관찰된 오류에 맞춰 한 단계씩 해결한다. 인증·네트워크·음성·렌더 중 막힌 경계를 먼저 확인하고, 같은 실패를 반복하거나 무음 대체본을 최종 교육영상으로 넘기지 않는다.

## 실제 화면과 교육 구성

1. 실제 서비스에서 학습 과업을 수행하고 최종 저장 결과까지 확인한다. 메뉴 이름·권한·요금제에 따라 보이는 화면이 다르면 해당 조건을 기록한다. 계정마다 달라지는 기능을 상상해 설명하지 않는다.
2. 조작 시연은 입력, 클릭, 메뉴 전환, 드래그, 커서 이동이 시간에 따라 기록된 실제 녹화를 사용한다. 정지 캡처에 가짜 커서를 움직인 결과를 실제 녹화로 소개하지 않는다. 사용자가 단계별 슬라이드 영상을 선택하면 그 형식을 유지하고 정확히 설명한다.
3. 개인정보가 없는 실습 자료와 필요한 창/탭만 촬영한다. 녹화 도구와 권한이 없으면 촬영됐다고 주장하지 말고, 사용자가 제공한 녹화로 진행하거나 필요한 클립 목록을 제공한다.
4. 장면을 '할 일 → 실제 조작 → 결과 확인 → 따라 할 시간'으로 구성한다. 따라 할 시간은 과업의 난이도에 맞춘다. 대기 구간과 실수는 편집하되 동작의 원인과 결과가 이어지게 한다.
5. 메뉴 글자가 읽히는 구간만 확대한다. 원래 커서와 필요한 확대를 우선하고, 강조 상자는 요청에 맞춰 사용한다. 상자를 쓸 때는 같은 프레임·해상도·확대 상태에서 위치를 확인하고 화면 전환 시 제거한다.

## 음성·자막·편집

- 사용자 녹음, 사용 가능한 TTS, 선택한 음성 도구 중 요청에 맞는 소스를 쓴다. 특정 유료 서비스나 개인 목소리를 필수로 만들지 않는다. 음성 복제는 해당 목소리 사용 권한을 확인한 경우에만 한다.
- 표시할 대본과 발음용 대본을 필요에 따라 분리한다. 화면에 '제작 중', '샘플' 같은 제작 메모를 학습 내용으로 남기지 않는다.
- 실제 음성 길이와 발화에 맞춰 장면·자막을 정렬한다. 글자 수로 타이밍을 확정하지 않는다. 짧은 의미 단위로 자막을 나누고 메뉴명·고유명사·줄바꿈을 교정한다.
- Remotion의 프레임 시간을 기준으로 녹화, 음성, 자막, 확대를 구성한다. 현재 설치 버전의 공식 문서로 컴포넌트·속성을 확인한다. 애니메이션은 프레임에서 계산하고 CSS 시간이나 랜덤값에 맡기지 않는다.
- 다국어판은 같은 학습 목표와 과업 순서를 유지하되 대상 언어의 메뉴 화면·음성·자막을 따로 맞춘다. 단순히 원본 자막만 번역한 것을 완전한 현지화로 소개하지 않는다.

## 검수와 전달

대표 장면의 화면·글자·음성·자막·실습 흐름을 먼저 확인해 긴 영상 전체의 재작업을 줄인다. 대표 장면의 상태 확인은 매번 사용자 승인을 요구하는 절차가 아니다. 요청 범위 안에서 계속 제작한다.

최종 파일은 [references/quality.md](references/quality.md)에 따라 확인한다. 기술 검사, 자동 음성 대조, 사람이 수행한 재생·청취를 각각 기록하고 미실시 검사를 통과로 쓰지 않는다. 영상이 바뀌면 최종 파일 해시와 검수 대상이 일치하도록 재검수한다.

요청한 MP4, 자막, 대본, 프로젝트 소스와 재현 명령을 전달한다. 썸네일·챕터는 필요할 때 포함한다. 파일 생성, 외부 업로드, 공개 게시, 기존 강의 교체는 각각 요청 범위에 따라 수행하고 실제 결과를 재조회한다.

# Canva 실행 경로 판단

## 기능별 API / UI 배정

시작할 때 연결된 도구의 스키마를 확인한다. 아래는 기능 분류이며 고정된 API 이름이나 지원 보장이 아니다.

| 작업 | 우선 경로 | UI가 필요한 상황 |
| --- | --- | --- |
| 검색·조회·복사·제목·문구 | 연결된 Canva 도구의 지원 API | 대상 디자인/요소가 편집 대상으로 제공되지 않음 |
| 장면 디자인·미디어 배치 | 현재 생성·편집 API | 영상 유형 또는 배치 작업이 지원되지 않음 |
| 미디어 업로드 | API의 허용 형식·입력 소스 확인 | 로컬 파일 등 해당 소스를 받지 못함 |
| 실제 조작 녹화 | 사용 가능한 화면/탭 녹화 도구 | 공유 선택창·녹화 시작/종료의 실제 조작 필요 |
| AI 음성·자막·시간 효과 | 해당 작업을 명시적으로 지원하는 API | 스키마에 기능이 없으면 Canva 편집기 사용 |
| 저장·최종 검수 | API 재조회와 실제 편집기 재생 | 움직임·음성 출력·유형·저장 상태 확인 |

이미지 위치를 바꾸는 API가 시간에 따른 이동 애니메이션도 설정한다고 추정하지 않는다. Canva 내장 앱에서 실행할 수 있는 SDK 기능과 외부에서 호출할 수 있는 API를 구분한다. 공식 문서는 [Canva 개발 문서](https://www.canva.dev/docs/)에서 현재 항목을 찾는다. 비공개 엔드포인트를 추측해 호출하지 않는다.

현재 도구가 영상 생성을 지원하지 않으면 프레젠테이션을 장면 디자인의 중간 산출물로 사용할 수 있다. 이 경우 Canva 안에서 동영상 유형으로 마무리해야 한다. 새 API가 지원하면 오래된 UI 절차보다 우선한다.

API가 저장 승인이나 미리보기를 요구하면 해당 절차를 따른다. 인증·권한 오류를 기능 미지원과 구분하고 UI로 권한을 우회하지 않는다. UI를 쓰기 전 남은 작업과 API에서 완료한 자료의 ID를 정리한다.

## 계정과 재개

API가 반환한 편집 URL로 동일 디자인을 열고 제목·장면을 대조한다. 접근이 안 되면 최신 조회 URL과 로그인 계정·팀을 확인한다. 공유 공개로 접근 오류를 해결하지 않는다. 새로운 디자인을 반복 생성하기 전에 기존 자료의 접근 경계를 확인한다.

상태 기록은 디자인 ID, 작업별 API/UI 경로와 이유, 장면별 길이, 생성된 음성/미디어 식별자, 마지막 저장과 검수 범위를 포함한다. 미디어 ID가 UI에서 보이지 않으면 파일명과 실제 관찰 내용을 기록하되 ID를 만들어내지 않는다.

## 녹화와 미디어

Canva 안의 녹화 메뉴와 외부 녹화 도구 중 실제로 제공되는 경로를 사용한다. 계정·기기별 메뉴 차이가 있으므로 고정 메뉴 경로를 보장하지 않는다. 화면 공유 선택창은 지원되는 네이티브 UI 도구 또는 사용자의 직접 선택으로 처리한다.

불필요한 카메라와 마이크는 끈다. 필요한 창/탭을 선택하고, 실제 동작과 녹화 길이, 저장된 클립을 확인한다. 설정 후 녹화 버튼이 비활성화되면 장치 선택·공유 대상·권한 상태를 살펴보고 녹화를 중복 시작하지 않는다.

자료를 API로 넣으려고 비공개 녹화를 공개 서버에 올리지 않는다. 영상 채우기 교체가 장면 길이 때문에 실패한 경우, 해당 작업의 제약을 확인하고 별도 영상 요소 삽입 등 지원 작업을 검토한다. 한 작업의 실패를 전체 API 미지원으로 일반화하지 않는다.

## 실제 재생

음성 트랙 볼륨, 편집기 음소거, 브라우저 탭/사이트 음소거, 기기 출력 상태를 구분한다. 음소거 설정을 바꿨다면 변경 뒤 출력 상태를 다시 확인한다. 자동화 탭에서 출력이 제한되면 지원되는 일반 탭에서 같은 디자인을 확인할 수 있다. 출력 감지를 사람이 전편 들었다는 증거로 사용하지 않는다.

# 결과 검수

[English](quality.en.md) · 한국어

- 원본 캡처와 장면 설명이 일치하는지, 클릭 네모가 실제 대상인지, 한글이 깨지거나 잘리지 않았는지 모든 프레임 이미지를 확인한다.
- 원본 개인정보와 제작 도구 잔여 표기가 가려졌는지 확인한다. 가림 후 이미지가 바뀌면 다시 검수한다.
- render.json의 최종 MP4 SHA와 전달하는 파일을 대조한다. 도구의 전체 디코드 검사와 실제 플레이어 재생을 구분한다.
- 파일에 H.264 영상 1920×1080과 AAC 음성이 있는지 확인하고 음성 무음·클리핑을 검사한다.
- SRT 시작/종료가 증가하고 영상 길이를 넘지 않는지 검사한다. 실제 발화와 문구·시점은 재생 또는 전사/정렬 도구로 별도 확인한다.
- 시작·중간·끝을 실제 플레이어에서 재생한다. 사람의 전편 청취를 하지 않았다면 그 사실을 결과에 남긴다.
- 결과 전달 범위는 MP4·SRT·대본·입력 자료·렌더 기록이다. 업로드·공개·기존 강의 교체 상태를 제작 성공으로 추정하지 않는다.

공통 완성 파일·SRT·대본 검사, 경고 처리, 목적지별 실제 반영 확인은 [재발 방지 기준](production-checks.md)을 따른다. 기술 검사로 발음이나 공개본 교체가 승인된 것은 아니다.

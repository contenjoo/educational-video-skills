# 저장과 내보내기 검수

## Canva 저장

- 동일 디자인의 제목·ID·편집 URL과 동영상 유형을 확인한다.
- 실제 녹화·사진·클립 등 요청한 자료가 들어 있고 임시 문구·빈 프레임이 없는지 확인한다.
- 장면 길이가 실제 음성에 맞고, 자막이 발화 및 장면 경계와 맞는지 확인한다.
- 움직임을 요청했다면 같은 장면의 다른 시점을 비교해 효과가 실제로 보이는지 확인한다.
- 시작·중간·끝을 재생하고 관찰한 시점과 오디오 확인 방법을 기록한다. 전편 청취·모바일 검수는 실제로 했을 때만 표시한다.
- 모든 변경 사항의 저장 완료 상태를 확인한다. API로 조회할 수 있는 제목·내용도 재조회한다.

## 사용자가 파일 내보내기를 요청한 경우

완료된 실제 파일을 확인한다. FFprobe 등으로 길이·해상도·fps·영상 및 오디오 스트림을 확인하고 가능하면 전체 디코드를 수행한다. 대표 프레임에서 실제 장면·자막을 확인한다. 파일 SHA-256을 남겨 검수 대상과 전달 대상이 같은지 확인한다.

MP4에 자막이 포함됐는지 별도 확인한다. 편집기나 발표 모드의 보기용 자막을 내보낸 영상 자막으로 간주하지 않는다. 외부 저장 요청은 원격 파일명·크기·형식과 실제 저장 위치를 다시 조회한다. 원격 체크섬이 없으면 대조하지 못했다고 기록한다.

전달할 때 Canva 저장, MP4 생성, 외부 저장, 공개 게시의 완료 여부를 구분하고 실제로 요청한 결과와 검수 범위만 간결하게 알린다.

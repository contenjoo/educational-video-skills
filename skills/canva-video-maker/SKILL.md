# 캔바영상 만들기

실제 자료와 음성 설명을 담은 편집 가능한 Canva 동영상 프로젝트를 만들고 편집 링크와 검수 범위를 전달한다. Claude와 Codex에서 공통으로 사용한다. 사용자의 계정·팀·언어·목소리·작업 경로를 사용하며 특정 개인 환경을 전제하지 않는다.

## 시작과 도구 선택

- 학습 대상, 할 과업, 분량, 언어, 화면 비율, 실제 화면 자료, 원하는 결과물을 파악한다. 미지정한 사소한 조건은 정해 알리고, 계정이나 핵심 자료가 필요할 때만 질문한다.
- 기존 작업을 이어갈 때는 디자인 ID와 실제 장면·음성 트랙을 먼저 확인한다. 이미 생성된 자료를 재사용한다.
- 연결된 Canva 도구와 지원되는 브라우저/컴퓨터 조작 도구를 확인한다. 어느 하나의 MCP 이름, 브라우저 브랜드, 운영체제에 의존하지 않는다. 각 기능의 실제 인자와 허용 작업을 확인하고 지원 API를 우선 사용한다.
- API가 없는 기능은 지원되는 UI 조작으로 수행한다. API가 없더라도 사용자가 자신의 편집기에서 따라 할 수 있는 장면표와 대본을 만들 수 있다. 편집 도구가 전혀 없으면 디자인이 저장됐다고 말하지 않는다. 도구 설치나 계정 연결이 필요한 지점을 구체적으로 알린다.
- 디자인 생성·편집과 녹화/타임라인 배정의 자세한 판단은 [references/canva-workflow.md](references/canva-workflow.md)를 읽는다.

## 학습 장면과 실제 자료

1. 학습 목표를 '이 영상을 보고 무엇을 완성하는가'로 정한다. 장면별 할 일, 화면 자료, 발화 대본, 결과 확인, 실습 시간을 연결한다. 실제 메뉴 이름과 제공 조건을 확인한다.
2. 조작 시연에는 실제 녹화를 사용한다. 캡처 확대·이동은 보조 설명에 쓸 수 있지만 화면 녹화로 부르지 않는다. 사용자가 슬라이드형을 요청하면 그 형식을 유지한다. 녹화 수단이 없으면 필요한 클립 목록을 제공하고 가능한 준비 작업을 진행한다.
3. 실제 화면은 필요한 창/탭에서 얻고 개인정보를 가린다. 사진·동영상은 출처와 사용 조건을 확인한다. 가상 UI를 실물처럼 제시하지 않는다.
4. 지원되는 도구로 장면과 자료를 배치한다. 실제 화면의 종횡비를 유지하고 작은 메뉴도 읽히게 한다. 효과는 학습자가 보는 곳을 안내하는 데 사용한다.

## 음성과 시간 배치

- 사용자가 Canva 내장 음성을 선택했다면 그 선택을 유지한다. 다른 TTS나 Remotion으로 임의 전환하지 않는다. 외부 음성이나 사용자 녹음을 선택했다면 지원되는 업로드 경로로 넣는다.
- 내장 음성의 언어, 화자, 요금 표시와 계정 사용 가능 여부를 현재 화면에서 확인한다. 특정 이름·무료 사용·목소리를 고정 약속하지 않는다. 유료 생성은 호스트와 사용자 승인 범위에 따른다.
- 음성 생성이 지연되거나 자동화가 끊기면 실제 트랙이 생겼는지 먼저 확인한다. 존재를 확인하기 전에 생성 버튼을 반복해서 누르지 않는다.
- 실제 음성 길이에 페이지와 다음 장면의 시작을 맞춘다. 장면 끝의 발화 잘림, 트랙 겹침, 불필요한 빈 페이지를 확인한다.
- 자막은 실제 음성을 기준으로 짧은 의미 단위로 생성·교정한다. 화면 요약 문구와 전체 발화 자막을 구분한다. 확대·이동·자막의 시간 효과는 실제 재생으로 확인한다.

## Canva 동영상으로 저장

최종 산출물은 동영상 유형의 디자인이어야 한다. 프레젠테이션으로 장면을 만들었다면 원본을 보존하고 현재 UI에서 지원하는 변환/동영상 복사본 경로를 확인한다. 변환 후 기존 음성·타이밍·자막이 유지됐는지 확인한다. 음성 프레젠테이션이나 MP4 내보내기 가능 여부만으로 동영상 프로젝트 완성이라 하지 않는다.

디자인 ID, 현재 편집 URL, 제목, 동영상 유형, 장면 수와 길이, 음성·자막, 저장 상태를 확인한다. 유형 API가 불명확하면 실제 파일 정보와 편집기 타임라인을 함께 확인한다. 시작·중간·끝 장면을 실제로 재생해 화면 전환, 움직임, 자막 교체, 오디오 출력을 확인하고 범위를 기록한다. 음성 트랙 존재, 음소거 해제, 출력 감지, 사람의 전편 청취는 구분한다.

기본 완료 지점은 Canva 저장과 편집 링크 전달이다. MP4 내보내기, Drive 업로드, 공개 공유, 기존 자료 교체는 요청에 포함될 때 수행한다. 다운로드 파일 보관은 사용자·호스트 정책을 따른다. 요청한 경우 [references/quality.md](references/quality.md)에 따라 내보낸 파일과 외부 저장 결과도 확인한다.

대본·출처·디자인 ID·장면/트랙 상태·API/UI 실행 경로·검수 결과를 작업 폴더에 남긴다. 인증값, 임시 서명 URL, 개인 계정 정보는 배포용 스킬에 넣지 않는다.

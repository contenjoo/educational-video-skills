# キャプチャから教育動画を作る

[한국어](SKILL.md) · [English](SKILL.en.md) · 日本語

実際の画面キャプチャ → 画面確認と台本の確定 → 場面ごとの音声 → Pillowによる画面カード → FFmpegによるエンコード → 再生確認の順で制作する。既存の制作手順を独立して使えるようにしたもので、非公開の教材や講座固有の規則は含まない。同梱のPythonレンダラーをローカルで使う。

## 使用言語

利用者が明示した言語を優先する。指定がなければ依頼文の言語で説明する。韓国語・英語・日本語に対応し、案内文の言語と動画・音声・字幕の言語は別々に扱う。別の動画言語が指定されていれば、その指定を維持する。日本語の固有名詞・読み方・実際のメニュー名を確認し、日本語対応フォントと音声を選ぶ。コマンド・API名・JSONキー・検査用ステータスは翻訳しない。

## 過去の失敗を繰り返さない

既存のプロジェクトを指定されたら、まず実際の入力とレンダラーを確認する。計画・台本 → 実画面の確認と台本修正 → 音声 → 短い完成見本と複雑な代表場面 → 一括制作 → 最終確認 → 依頼された公開先の確認、の順で進める。画面・強調位置・不自然な音声を大量制作の前に直す。各段階で承認を取り直すという意味ではない。

実行前に[制作時の確認事項](references/production-checks.ja.md)を読み、今回に関係する項目を適用する。クリック前後の状態、強調表示のタイミング、台本・音声・カリキュラムの一致、言語別の納品物、学習者に見える版を確認する。既存の有効な検査結果と記録を再利用し、書類を増やさない。同梱の `scripts/check_media.py` で最終ファイル・SRT・承認済み表示台本を照合し、自動検査では判断できない項目は未確認とする。

## 開始

- 対象者、学習目標、長さ、制作言語、素材を確認する。確認済みの機能だけを説明し、既存の成果物を保全する。
- Python 3.9以上、Pillow、FFmpeg/FFprobe、制作言語に対応したフォントを用意する。スキルのフォルダーで `python3 scripts/preflight.py --mode canva` を実行する。`canva` は互換性のため維持しているモード名である。[実行方法と入力仕様](references/capture-workflow.ja.md)を読む。
- ターミナルを実行できない環境では入力の準備まで行い、レンダリング済みとは報告しない。特定のコネクター名・個人用パス・声を前提にしない。

## 画面と台本

1. 利用者が提供した実際のスクリーンショット・録画、または対応するブラウザーツールで取得した素材を使う。録画からフレームを抽出するときは元ファイルと時間範囲を記録する。静止画を連ねた動画はキャプチャベースと明記する。
2. 個人情報を隠し、読みやすく切り抜く。実際のクリック対象を番号のない四角で示す。隠れたメニュー、失敗した操作、文字のはみ出しを成功例として扱わない。
3. 対象画像を実際に確認し、そのSHA-256を記録してから `image_review` を承認する。確認者・時刻・取得証拠を捏造しない。
4. 一場面で一つの操作を短く自然に説明する。結果の確認と練習時間を設ける。学習者向け画面から制作メモや不要なツール名を除く。

## 音声とレンダリング

- 本人の録音または選択されたTTSを使う。外部サービスを使う場合は利用可能なモデル・声と実際の生成記録を確認する。非公開の有料音声や個人アカウントを必須にしない。
- 場面ごとの音声ファイル、ハッシュ、実際の取得元を用意する。音声抜け、無音、読み間違い、制御タグの読み上げを確認する。再生速度を維持し、練習用の間は発話後に入れる。
- 毎回レンダラーを書き直さず `scripts/render_lesson.py` を再利用する。`--frames` の完成カードを実際に確認し、preview.jsonの正確なPNG SHAで各 `preview_review` を記録した後、`--validate` と最終レンダリングを行う。配置・文言・強調を変えたらプレビューを再確認する。既存の出力は上書きしない。
- 同梱レンダラーは静止画の場面、強調表示、音声、要約カード、全文SRTを作る。連続操作の録画編集や複雑な動きが不可欠ならRemotion方式を提案する。利用者がこの方式を明示した場合はその選択を尊重する。

## 確認と納品

[品質確認](references/quality.ja.md)に従い、デコード、サイズ、音声、字幕の時間範囲、冒頭・中盤・末尾の再生を確認する。SRTは短い句に分け、承認済み台本の全文と照合する。標準の時間は場面内音声に基づく推定であり、単語単位の整列ではない。検証済みの場面相対 `subtitles` があれば使う。文字起こしや強制アラインメントが使えなければ限界を明記する。自動検査、AIによる画面確認、人による全編視聴・聴取を区別する。

MP4、SRT、台本、lesson.json、画面・音声素材、レンダリング記録を渡す。標準の完了範囲はローカル制作である。アップロード・公開・既存講座の差し替えは対応する依頼がある場合に行う。問題が起きたら[初回実行のトラブル対応](references/first-run.ja.md)を使う。
